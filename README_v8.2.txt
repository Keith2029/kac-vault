KAC Vault Website v8.2

Changes from v8.1:
- Every inventory record C-0001 through C-0040 now has a permanent individual HTML page.
- Every inventory JSON record now has a permanent slug: item-c-XXXX.html.
- Inventory cards link directly to their permanent record pages.
- Items without photographs display a PHOTO PENDING permanent-record page; adding photography later does not change the URL or SKU.
- Existing photographed CGC records C-0036 through C-0040 remain supported with their galleries.
- Removed obsolete typo duplicate item-c0036.html.

Permanent URL pattern:
https://kacvault.com/item-c-0001.html
...
https://kacvault.com/item-c-0040.html
